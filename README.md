# 🎓 Student Exam Score Prediction

> **End-to-end machine learning project** — from raw CSV to a deployed Streamlit app

---

## 📌 Problem Statement

Given 19 features about a student (study habits, attendance, lifestyle, family background), predict their **Exam Score** (0–100). This is a **supervised regression** problem.

The dataset is publicly available on Kaggle:  
🔗 [Student Performance Factors — Kaggle](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)

---

## 📂 Dataset

| Property | Value |
|---|---|
| Rows | ~6,600 students |
| Columns | 20 (19 features + 1 target) |
| Target | `Exam_Score` (continuous, 55–101) |
| Numeric features | Hours_Studied, Attendance, Sleep_Hours, Previous_Scores, Tutoring_Sessions, Physical_Activity |
| Categorical features | Parental_Involvement, Access_to_Resources, Extracurricular_Activities, Motivation_Level, Internet_Access, Family_Income, Teacher_Quality, School_Type, Peer_Influence, Learning_Disabilities, Parental_Education_Level, Distance_from_Home, Gender |

---

## 🛠️ Approach

```
Raw CSV
  └── Step 1: Load & Inspect (shape, dtypes, missing values)
  └── Step 2: EDA (distributions, correlations, box plots)
  └── Step 3: Preprocessing Pipeline
        ├── Numeric: median imputation → StandardScaler
        └── Categorical: most-frequent imputation → OneHotEncoder
  └── Step 4: 80/20 Train–Test Split (random_state=42)
  └── Step 5: 5-Fold CV — Linear Regression, Ridge, Random Forest, Gradient Boosting
  └── Step 6: Hyperparameter Tuning (RandomizedSearchCV + GridSearchCV)
  └── Step 7: Test Set Evaluation (Predicted vs Actual, Residual plots)
  └── Step 8: Feature Importance + SHAP
  └── Step 9: Save pipeline with joblib
  └── Step 10: Streamlit app (app.py)
```

## 💡 Key Insights

1. **Previous Scores is the strongest predictor** — prior academic performance is the best indicator of future results.
2. **Attendance matters greatly** — consistently showing up to class has a strong positive effect on exam scores.
3. **Study hours show diminishing returns** — studying more helps, but the relationship isn't perfectly linear.
4. **Social environment counts** — Positive peer influence and High parental involvement both shift the score distribution upward.
5. **Tutoring helps, but is not a silver bullet** — a few sessions add value; excessive tutoring may indicate struggling students rather than cause improvement.

---

## ⚠️ Limitations

- **Dataset may be partly synthetic** — the data was generated/sourced from Kaggle and may not reflect real-world classroom noise. Models trained here may look cleaner than production results.
- **No causal inference** — correlations do not imply causation. High attendance might be a proxy for motivation, not the direct cause of better scores.
- **Missing socioeconomic context** — factors like school district quality, teacher-to-student ratio, and mental health are not captured.
- **Static snapshot** — this is a cross-sectional dataset; longitudinal tracking would reveal more actionable patterns.

## 🚀 How to Run

### 1. Clone / download the repository
```bash
git clone <your-repo-url>
cd student-performance-ml
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Place the dataset
Ensure `StudentPerformanceFactors.csv` is in the project root.

### 4. Run the Jupyter notebook
```bash
jupyter lab student_performance_ml.ipynb
# or in Google Colab: File → Upload → run all cells
```

The notebook will:
- Train all models
- Save the pipeline as `student_score_pipeline.joblib`
- Save all plots as PNG files

### 5. Launch the Streamlit app
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.

## 🔮 Ideas for Future Improvements

1. **Try XGBoost / LightGBM** — often outperform sklearn's GradientBoosting on tabular data.
2. **Add cross-school comparisons** — if school IDs were available, mixed-effects models could account for school-level clustering.
3. **Deploy on Streamlit Cloud / Hugging Face Spaces** — share the app publicly with a single `git push`.
4. **Collect real data** — partner with schools to gather authentic, longitudinal student data with more granular features.
5. **Add uncertainty estimates** — use quantile regression or conformal prediction to give score ranges instead of point estimates.
6. **Class imbalance / extreme scores** — explore whether students at the tails (very low or very high scorers) are underfit, and apply targeted oversampling or cost-sensitive learning.
